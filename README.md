# Анализ взаимосвязи физических показателей по данным фитнес-часов

НИРС по дисциплине «Оперативный анализ данных» 5 семестр ИУ5

## Тема
Исследование взаимосвязей между физическими показателями (шаги, пульс, калории, сон, активность) на данных фитнес-часов.

## Стек
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Задачи
- Загрузка и предобработка данных фитнес-трекера
- Описательная статистика по показателям
- Корреляционный анализ (Пирсон / Спирмен)
- Визуализация зависимостей: scatter, heatmap, распределения
- Выводы о силе и направлении связей между показателями
